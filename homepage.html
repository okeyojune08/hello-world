Welcome to fullstack foundry

The web is made of many connected parts. Fullstack foundry is a place to explore how they work together and start creating complete web applications, from the first screen to the data behind it.

explore the fundamentals

what does fullstack foundry mean?

A full-stack web applications brings together the parts people see and use with the services and data that make those experiences work. Understanding the whole stack helps you build featueres from end to end

The building blocks

Fronted

The frontrd is the part of an application that runs in the browser. It presents information, responds to user actions, and makes a product usable.

Backened

The backened handles the work behind the scenes, such as applying applications rules, processing requests, and coordinating access to data.

Database

Database stores and organize information so an application can retrieve, update, and manage it when needed.

APIs

APIs define how different parts of a system communicate. Abrowser can use an API to request information or send changes to a backened.

A practical path to getting started

  1. Learn the foundations of the web and how browsers load pages.
  2. Build clear, accessible interfaces to application data.
  3. Add behaviour and connect the interfaces to application data.
  4. Practice sending requests between fronted and backened.
  5. Bring the pieces together in a small end-to-end project.

Start with the basics, keep experimenting, and let each project teach you something new.
